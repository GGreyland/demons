Памятка демонолога

  • На поле скрываются 20 демонов разных размеров (1шт-4кл, 2шт-3кл, 3шт-2кл, 4шт-1кл).
  • Они располагаются по правилам "Морского боя": по прямой линии, и никогда не соприкасаются друг с другом.
  • У вас есть 50 ловушек для поиска.
  • Кликайте по клеткам, чтобы установить ловушки ⛧.
  • Нажмите "ПРОВЕРИТЬ", чтобы активировать установленные ловушки.
